Thả file nhạc nền vào đây với tên: nhac.mp3

  - Khoảng 2 phút, <= 2MB (khách mở bằng 4G).
  - Nhạc chỉ phát SAU khi khách bấm "Mở thiệp" — đó là user-gesture hợp lệ,
    nếu tự phát ngay khi vào trang thì trình duyệt sẽ chặn.
  - Không có file này thì nút bật/tắt nhạc tự ẩn, trang vẫn chạy bình thường.

Đổi tên file khác thì sửa MUSIC.src trong src/config.js.
